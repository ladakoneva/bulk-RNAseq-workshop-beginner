# bulk-RNAseq-workshop-beginner
Beginner bulk RNA‑seq differential expression workshop in R (breast cancer E‑GEOD‑52194)

This is a small project to analyse data from the count matrix: https://www.ebi.ac.uk/gxa/experiments/E-GEOD-52194/Downloads
Description: RNA-seq of 17 breast tumor samples of three different subtypes and normal human breast organoids samples.
